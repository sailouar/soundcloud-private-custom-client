# Phase 2 Plan 1: Personal Sign-In and Keychain Session

**Make the sideloaded app able to sign in with the owner's own SoundCloud developer app, keep the session in the Keychain, and recover from failures without a password flow.**

## Tasks

1. Add `LocalizedError` descriptions for the typed core failures so every failure
   is readable and retryable in the UI.
2. Add app-target adapters: Keychain records/token store, app credential store,
   `ASWebAuthenticationSession` browser, and `URLSession` OAuth transport.
3. Add `AuthenticationCoordinator` with setup, sign-in, restore, sign-out, and
   reset states; derive the redirect URI from `Info.plist`.
4. Wire the app shell: `AppEnvironment` owns the coordinator, the root view shows
   an Account tab, and startup restores the session.
5. Register the `soundcloudpersonal` URL scheme and add the new app files to the
   Xcode project.
6. Add the personal AltStore build lane, `.gitignore`, and synchronized docs.

## Verification

- Windows: artifact presence, plist parse, Xcode project reference audit, policy
  scan (no password flow, no hidden media extraction, no committed secrets).
- Pending on cloud Mac/device: `swift test`, `xcodebuild test`, IPA archive,
  AltServer install, real SoundCloud sign-in, Keychain restore after re-sign.
