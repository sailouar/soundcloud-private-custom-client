# Product Roadmap

1. Validate official API/auth/download capabilities and set up the SwiftUI architecture.
2. Implement secure authentication and session restoration.
3. Implement discovery, search, account library, and supported social actions.
4. Implement native streaming and background playback.
5. Implement authorized downloads, deduplication, metadata, and offline playback.
6. Implement local collections and supported remote playlist synchronization.

The detailed tracked roadmap is [`../.planning/ROADMAP.md`](../.planning/ROADMAP.md).
