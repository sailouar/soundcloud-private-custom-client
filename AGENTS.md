# Copilot Instructions

- Read this file before making changes.
- Keep implementation and the Markdown files in `docs/` synchronized.
- Do not claim a feature is implemented until it works and is verified.
- Use only officially supported SoundCloud APIs and authorization flows.
- Never scrape hidden media URLs, bypass access controls, or circumvent DRM.
- Keep the app native Swift/SwiftUI and preserve a modular service boundary.
- Treat offline files as permitted downloads only; streaming is not download authorization.
- Update `docs/CHANGELOG.md` and the relevant subsystem document for meaningful changes.
- Prefer small, testable changes and document known platform limitations.
